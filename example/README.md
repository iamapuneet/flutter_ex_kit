# Example for flutter_ex_kit

This directory demonstrates how to use the extensions and utilities provided by `flutter_ex_kit`.

## Running the Example

1. Open the project root or navigate to the `example` folder:
   ```bash
   cd example
   ```

2. Get dependencies:
   ```bash
   flutter pub get
   ```

3. Run the app on your preferred device or simulator:
   ```bash
   flutter run
   ```

## Highlights Demonstrated

- **SizedBox Utilities:** `10.height` and `10.width`
- **Padding Extensions:** `.only(left: 10, right: 10)`
- **Number Helpers:** `.ordinal` and `.roman`
