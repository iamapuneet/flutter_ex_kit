## 0.0.7

- Added comprehensive BuildContext extensions (`width`, `height`, `isDarkMode`, navigation, snackbars, keyboard).
- Added Duration and async delay extensions on `num` (`seconds`, `milliseconds`, `delay`).
- Added DateTime extensions (`isToday`, `isYesterday`, `timeAgo`, `toDateString`).
- Added Collections & Iterable extensions (`firstWhereOrNull`, `mapIndexed`, `isNullOrEmpty`).
- Added Widget layout extensions (`expanded`, `flexible`, `opacity`, `onTap`, `safeArea`).
- Fixed critical bugs: `exitApp` timestamp return, `networkImage` CDN query parameter parsing, and stateless `SingleSpaceFormatter`.
- Restructured `flutter_ex_kit.dart` with clean barrel exports.
- Added comprehensive unit tests and improved example application.
- Added GitHub Actions CI/CD with automated pub.dev publishing via OIDC.
