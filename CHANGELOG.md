- Implemented input validation for strings and integers.

- Added comprehensive BuildContext extensions (`width`, `height`, `isDarkMode`, navigation, snackbars).
- Added Duration and async delay extensions on `num` (`seconds`, `milliseconds`, `delay`).
- Added DateTime extensions (`isToday`, `timeAgo`, `toDateString`).
- Added Iterable extensions (`firstWhereOrNull`, `mapIndexed`, `isNullOrEmpty`).
- Added Widget layout extensions (`expanded`, `flexible`, `opacity`, `onTap`, `safeArea`).
- Restructured `flutter_ex_kit.dart` with clean barrel exports.
- Added comprehensive unit tests and improved example application.
